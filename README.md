# 洛克王国精灵捕捉保底工具

一个专门为洛克王国玩家设计的精灵捕捉保底进度追踪工具，帮助你轻松记录和统计精灵捕捉次数，掌握保底机制。

## 功能特点

### 🎯 核心功能
- **一键记录**: 简单点击即可添加捕捉记录
- **保底计算**: 自动计算80次普通保底噩梦，80次噩梦保底异色
- **双人模式加成**: 双人模式自动提升概率（20%加成）
- **实时进度**: 实时显示当前捕捉进度和剩余次数

### 📊 统计功能
- **详细统计**: 显示总记录数、各类型精灵数量
- **进度可视化**: 彩色进度条直观显示保底进度
- **历史记录**: 完整的捕捉历史记录查看

### 💾 数据管理
- **本地存储**: 数据自动保存在浏览器本地
- **数据安全**: 清空记录需要确认操作
- **快捷键支持**: 支持键盘快捷键操作

## 使用方法

### 基本操作
1. **选择精灵类型**: 在下拉菜单中选择捕捉的精灵类型（普通/噩梦/异色）
2. **选择模式**: 选择单人模式或双人模式
3. **添加记录**: 点击"添加记录"按钮或按回车键
4. **查看进度**: 实时查看保底进度和统计信息

### 保底机制
- **普通精灵**: 80次保底获得噩梦精灵
- **噩梦精灵**: 80次保底获得异色精灵
- **双人模式**: 概率提升20%

## 界面说明

### 主要区域
1. **添加记录区域**: 选择精灵类型和模式，添加新记录
2. **进度显示区域**: 显示普通和噩梦精灵的保底进度
3. **统计信息区域**: 显示各类精灵的统计数量
4. **历史记录区域**: 查看所有捕捉记录的时间线

### 颜色标识
- **普通精灵**: 蓝色标识
- **噩梦精灵**: 红色标识  
- **异色精灵**: 黄色标识

## 技术特点

- **响应式设计**: 支持手机和电脑端访问
- **现代UI**: 美观的渐变色彩和动画效果
- **本地存储**: 无需服务器，数据安全保存在本地
- **无依赖**: 纯HTML/CSS/JavaScript实现

## 开始使用

1. 直接打开 `index.html` 文件即可使用
2. 无需安装任何软件或插件
3. 数据自动保存在浏览器中

## 注意事项

- 数据保存在浏览器本地存储中，清除浏览器数据会丢失记录
- 建议定期备份重要数据
- 双人模式加成仅为参考，实际游戏概率以官方为准
